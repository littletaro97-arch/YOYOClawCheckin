YOYO Claw 每日自动签到  v1.3
=====================================

【v1.3 变更】
  * 触发方式从"启动文件夹"改成"计划任务"：登录时 + 每天 12:00 / 20:00。
    旧方式只在登录系统那一刻执行一次；机器长期不注销、不重启、只在睡眠和唤醒
    之间来回时，会整天整天地漏跑。这个坑已在新版修掉。
  * 后台运行时不再闪出控制台黑框（子进程全部隐藏窗口）。
  * 配置 / 解除配置改成两个 bat，不再往系统启动目录里塞东西。

【它做什么】
  在你自己的电脑上、用你自己已登录的荣耀账号，每天检查 YOYO Claw 的积分签到
  有没有领；没领就领一次。
  只调客户端自己调的那个接口，一天最多领一次，领过就跳过，不会重复刷。
  全程不联网上传任何东西，不收集账号密码。

【前提】（重要）
  1. 电脑上装了荣耀 YOYO Claw（MagicClaw），并且**已经登录你自己的荣耀账号**。
     没登录的话程序会明确报"没有登录荣耀账号"，不会瞎重试。
  2. Windows 10 / 11，64 位。
  3. 不需要自己装 Python —— 包里自带了一个精简版 Python。
  4. 一台电脑一个账号。请不要拿它给别人代签，也不要改成批量请求。

【怎么用】（三步）
  1. 把整个文件夹解压到任意位置（建议放个不常动的地方，比如
     D:\Tools\YOYOClawCheckin）。路径里有中文没关系。
     注意：解压后不要只把 bat 单独拷出来，程序需要同目录下的 python 子目录。
  2. 双击「一键配置.bat」。
     它会注册计划任务，然后**立刻真跑一次签到**，当场告诉你成没成。
     看到"[成功] 配置完成"就完事了。
  3. 想确认它平时在不在干活，双击「查看运行日志.bat」。

【它什么时候运行】
  用 Windows 计划任务，名字 YOYOClawCheckin，一共 3 个触发点：
    - 每次登录系统时
    - 每天 12:00
    - 每天 20:00
  另外勾了"错过时间后尽快启动"：比如 12:00 那会儿电脑关着或在睡眠，
  等它醒过来会补跑一次。
  所以一天最多跑 3 次。第一次领到之后，后面几次会在读本地记录时直接跳过，
  重复运行不会重复领取，也不会多刷接口。

【有没有界面】
  自动运行那次**完全静默**：没有窗口、没有托盘图标、不会闪黑框，你感觉不到它跑过。
  只有一种情况会弹窗：重试 2 次后仍然失败（比如没登录、断网），才会弹一次说明原因。
  成功、或者"今天已经签到过"，都不会弹任何东西。
  想主动看结果：双击「立即签到.bat」，或者「查看运行日志.bat」。

【退出码】
  0  成功 / 今天已经签到过
  2  等不到登录态刷新
  3  查询签到状态失败（多为网络不通）
  4  领取失败
  5  领取已提交，但复核时服务端还没显示已签到
  6  本机没找到 YOYO Claw
  7  没有登录荣耀账号
  8  注册 / 注销计划任务失败
  2/3/4/5 会自动重试（间隔 15 秒，最多再试 2 次）；6/7/8 不重试。

【常见问题】
  Q: 报"没找到 YOYO Claw"？
  A: 确认装了客户端。如果装在很特殊的位置，设一个系统环境变量
     YOYOCLAW_ROOT 指向安装目录里包含 current.json 的那一层。
     客户端升级换版本子目录（例如现在的 20.0.0.10(SP3)）不用管，
     程序会读注册表和 current.json 自己跟过去。

  Q: 报"没有登录荣耀账号"？
  A: 打开 YOYO Claw 确认已登录，然后重新双击「一键配置.bat」或「立即签到.bat」。
     这个错误不会自动重试，因为再试也没用。

  Q: 一键配置时提示注册计划任务失败（退出码 8）？
  A: 极少数机器会用组策略限制计划任务或 PowerShell。把窗口截图发给分享给你的人。

  Q: 杀毒软件报警？
  A: 程序需要解密本机 YOYO Claw 的登录态（Windows DPAPI），
     这个行为和浏览器读取自己的 Cookie 属于同一类操作，个别杀软会按特征误报。
     源码 YOYOClawCheckin.py 是明文，可以自己打开看；
     依赖只有 Python 标准库，没有任何第三方包。

  Q: 当天那次失败了，还会自动补吗？
  A: 会。程序内部失败会重试 2 次；计划任务配了"错过就尽快补跑"，
     另外每天还有 12:00 / 20:00 两个检查点；
     最后你随时可以双击「立即签到.bat」手动补，当天都还来得及。

  Q: 连续签到天数怎么查？
  A: 「查看运行日志.bat」里那行"连续=N 天"就是服务端返回的实时值。

【解除配置 / 卸载】
  1. 双击「一键解除配置.bat」—— 删除计划任务，不再自动签到。
  2. 然后把整个文件夹删掉。
  3. 签到记录和日志在 %LOCALAPPDATA%\YOYOClawCheckin\
     （也就是 C:\Users\你的名字\AppData\Local\YOYOClawCheckin），
     不需要就一起删掉，删了就彻底干净。
  本程序不改动 YOYO Claw 本身，也不会动你的荣耀账号数据。

【附录：转发给别人 / 排障时看】
  * 包内 python\ 是 Python 3.12.10 官方 embeddable 版的精简子集，按 PSF 许可证
    分发，许可证原文见 python\LICENSE.txt ——再转发时**请不要删它**。
  * 实测结论，别乱删：
      - python\select.pyd       不能删，socket / selectors 依赖它，删了直接起不来
      - python\unicodedata.pyd  不能删，删了 HTTPS 立刻报 unknown encoding: idna
      - _hashlib.pyd / _uuid.pyd / python3.dll 实测可以不删也不影响，
        但一共只有 166 KB，留着当保险，不建议动
      - python312.zip 里的标准库没有再裁剪：能省的那点体积（个位数 MB）
        换来的是"在别人机器上偶发 import 失败"的风险，不划算
  * YOYOClawCheckin.py 只依赖标准库，没有第三方包，可以直接读源码审计。
  * 计划任务用的是"只在用户登录时运行"（InteractiveToken）。这是必须的：
    脚本要用用户级 DPAPI 解密 session.bin，非交互会话里没有加载的用户配置
    文件，解不开。副作用是注销状态下 12:00 / 20:00 不会触发，靠登录触发器兜底。
